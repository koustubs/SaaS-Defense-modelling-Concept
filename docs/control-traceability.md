# Control Traceability

This table connects the modern threat register to preserved evidence, implemented controls, and exact automated tests. “Original evidence” describes what the 2025 models or reports show; absence of a control from a sequence diagram is a review signal, not proof that an implementation lacked that control. Status and qualitative risk values are maintained in [`config/threat_register.json`](../config/threat_register.json).
